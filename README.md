# Socket.io Chat App

A real-time chat application built with React and Socket.io.

## Tech stack

- **Client:** React 19 + Vite
- **Server:** Node.js, Express 5, Socket.io 4

## Project structure

```
.
├── client/   # React frontend (Vite dev server on http://localhost:5173)
└── server/   # Express + Socket.io backend (http://localhost:5000)
```

## Getting started

### Prerequisites

- Node.js 20+ and npm

### Run the server

```bash
cd server
npm install
npm run dev
```

### Run the client

```bash
cd client
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.
